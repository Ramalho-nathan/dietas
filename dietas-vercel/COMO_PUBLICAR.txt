VERSÃO 1.3 — EXPORTAÇÃO NO MODELO ORIGINAL

Substitua os arquivos do seu projeto por esta versão, envie ao GitHub e faça um novo deploy na Vercel.

Configuração: Vite; npm ci; npm run build; saída dist.

Para executar no Windows, abra a pasta dietas-vercel no VS Code:
npm ci
npm run dev

Leia README.md para as instruções completas.
